## 🏠 Главное меню

![Главное меню](01_main_menu.svg)

Дашборд Расширенного режима с информацией о:
- Активной цели (панель Remnawave / бот) и её контейнере
- Количестве и размере бэкапов, времени последнего
- Состоянии защиты (шифрование · off-site · авто-бэкап) и расписания

> 💡 В 6.0 есть и **Простой режим** (4 пункта для новичков) — переключается пунктом 99.

## ⚙️ Настройки

![Настройки](02_settings.svg)

Конфигурация системы по разделам:
- **Что бэкапим**: цель бэкапа (панель / бот / обе), доп. компоненты (infra-billing · KB)
- **Куда доставляем**: Telegram, удалённое хранилище (S3/FTP/WebDAV/Rclone)
- **Как храним**: шифрование (AES-256), ротация и диск, компрессия

## 🐛 Debug режим

![Debug режим](05_debug_mode.svg)

Запуск: `lazarus --debug`

Расширенный вывод включает:
- Конфигурационные переменные
- Команды Docker
- Детали шифрования
- Полный TLS handshake с Telegram API
- Время выполнения

---

## 📦 Процесс бэкапа

![Процесс бэкапа](06_backup_process.svg)

Последовательность операций:
1. Снимок живой БД (точка отката)
2. Создание дампа БД + сайдкаров (роли, infra-billing, KB)
3. Архивация файлов
4. Шифрование (AES-256-CBC + HMAC)
5. Проверка целостности
6. Отправка в Telegram / удалённое хранилище
7. Ротация старых бэкапов
